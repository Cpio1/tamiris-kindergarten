# «Тамирис» — сайт детского сада

Лендинг частного детского сада «Тамирис» (Алматы). Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, Motion (только десктоп), Lucide.
Языки: казахский (по умолчанию) и русский; выбор сохраняется в браузере и не теряется при переключении между версиями.

Сайт состоит из двух самостоятельно спроектированных интерфейсов — **для компьютеров/планшетов** и **для телефонов** — которые открываются по **одному адресу**.

## Структура

```text
tamiris-kindergarten/
├── website/          ← Next.js-приложение (единая точка входа, деплоится на Vercel)
│   ├── public/       ← все фотографии (общие для обеих версий)
│   └── src/
│       ├── app/
│       │   ├── layout.tsx          корневой layout: шрифты, язык, SEO, JSON-LD
│       │   ├── (desktop)/          десктопная страница + desktop.css
│       │   └── mobile/             точка монтирования мобильной версии (внутренний путь)
│       ├── components/             десктопные компоненты (motion, мозаика галереи и т.д.)
│       └── middleware.ts           выбор версии по cookie
├── mobile-website/   ← мобильный интерфейс (свои компоненты и стили)
│   └── src/
│       ├── app/                    page.tsx, mobile.css
│       └── components/             Hero, About, Info, Gallery, Lightbox, Documents, Contacts, Footer…
├── shared/           ← общее для обеих версий — единственный источник данных
│   └── src/
│       ├── config/                 site.ts (контакты, адрес, часы, возраст, группы…), view.ts (переключение версий)
│       ├── i18n/                   переводы ҚАЗ / РУС и LanguageProvider
│       ├── lib/                    поиск фотографий, SEO
│       ├── styles/theme.css        фирменная палитра и шрифты (@theme)
│       └── ui/                     SVG-декор, логотип, иконки, ViewSync
├── package.json      ← npm workspaces
└── eslint.config.mjs
```

## Как выбирается версия

Адрес один: `/`.

1. `website/src/middleware.ts` смотрит cookie `tamiris-view`. При первом визите версия угадывается по User-Agent: телефон сразу получает мобильную версию.
2. Встроенный скрипт `shared/src/ui/ViewSync.tsx` проверяет **реальную ширину окна**: до 767 px — мобильная, от 768 px — десктопная. Если версия не совпала, он записывает cookie и один раз перезагружает страницу (адрес и якорь сохраняются). При изменении ширины окна через границу версия тоже переключается.
3. Перезагрузка происходит только если cookie действительно записался — без бесконечных циклов при заблокированных cookie (тогда показывается десктопная версия, у неё есть адаптивная вёрстка).
4. Мобильная версия внутри приложения живёт по пути `/mobile`, но посетитель его не видит: middleware переписывает `/` → `/mobile`, а прямой заход на `/mobile` перенаправляет на `/`.

Каждая версия загружает только свои стили и скрипты: мобильная не подключает `motion` и десктопный CSS.

## Запуск

```bash
npm install          # из корня репозитория — ставит зависимости всех пакетов
npm run dev          # http://localhost:3000
npm run build        # production-сборка (обе версии собираются вместе)
npm start            # запуск собранного сайта
npm run lint         # ESLint для website, mobile-website и shared
npm run typecheck    # TypeScript
```

Чтобы посмотреть мобильную версию на компьютере, сузьте окно до ширины меньше 768 px или включите эмуляцию устройства в DevTools — сайт переключится сам.

## Деплой на Vercel

Один проект Vercel, один домен.

1. **Settings → Build and Deployment → Root Directory: `website`.** Опция «Include files outside the root directory in the Build Step» должна быть включена (для новых проектов включена по умолчанию) — приложение компилирует `../shared` и `../mobile-website`.
2. Framework Preset — Next.js; команды сборки и установки оставьте по умолчанию: Vercel распознаёт npm workspaces и ставит зависимости из корня.
3. Переменные окружения — см. ниже и `website/.env.example`.

> Если проект на Vercel уже был подключён к репозиторию с Root Directory = `./`, после этого обновления Root Directory нужно сменить на `website`, иначе сборка не найдёт приложение.

## Фотографии

Все фото лежат в `website/public/`. Поддерживаются `.jpg .jpeg .png .webp .avif`.

| Имя файла          | Где используется                                      |
| ------------------ | ----------------------------------------------------- |
| `main-page.*`      | Главный экран (Hero)                                  |
| `main-page2.*`     | Раздел «О садике» — показывается целиком, без обрезки |
| любые другие       | Галерея (из `website/public/images/`)                 |

`main-page.*` и `main-page2.*` можно положить и в `website/public/images/`, и прямо в `website/public/` — сначала ищется в `images/`.

В галерею не попадают `logo.*`, `favicon.*`, `icon.*`, `og.*`, скрытые файлы и точные копии других фото.

- Десктоп: мозаика, фото раскладываются по ячейкам по пропорциям.
- Телефон: ряды по форме — вертикальные парами, горизонтальные парами (4:3), панорамы на всю ширину в своих пропорциях. Сначала 4 фото, остальные — по кнопке «Барлық суреттерді көру». Очень вытянутые кадры показываются целиком, без жёсткой обрезки.

Список фото собирается **при сборке**. После добавления фото пересоберите проект (на Vercel — новый деплой).
Совет: перед загрузкой уменьшайте фото до ~2000 px по длинной стороне.

## Переменные окружения

- `NEXT_PUBLIC_DOCUMENTS_URL` — необязательно. Ссылка на папку Google Drive с документами уже указана в `shared/src/config/site.ts` (`documentsUrl`) и используется обеими версиями; переменная нужна, только чтобы временно подменить её без изменения кода.
- `NEXT_PUBLIC_SITE_URL` — домен сайта (например `https://tamiris.kz`) для canonical, sitemap, robots и Open Graph. На Vercel без неё берётся production-домен проекта.

## Где что менять

| Что | Файл |
| --- | --- |
| Телефоны, Instagram, адрес, режим работы, возраст, число групп, питание | `shared/src/config/site.ts` |
| Все тексты ҚАЗ / РУС (обе версии) | `shared/src/i18n/translations.ts` |
| Цвета и шрифты | `shared/src/styles/theme.css`, `website/src/app/layout.tsx` |
| Граница между версиями (767 px) | `shared/src/config/view.ts` |
| Десктопный дизайн | `website/src/components`, `website/src/app/(desktop)/desktop.css` |
| Мобильный дизайн | `mobile-website/src/components`, `mobile-website/src/app/mobile.css` |

Факты (часы, возраст, группы, питание) задаются один раз в `site.ts` — тексты в переводах собираются из них, поэтому обе версии обновляются одновременно.
