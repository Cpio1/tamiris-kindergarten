# «Тамирис» — сайт детского сада

Лендинг частного детского сада «Тамирис» (Алматы). Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, Motion, Lucide.
Языки: казахский (по умолчанию) и русский; выбор сохраняется в браузере.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm start          # запуск собранной версии
npm run lint       # ESLint
npm run typecheck  # TypeScript
```

## Фотографии

Все фото кладутся в `public/images/`. Поддерживаются `.jpg .jpeg .png .webp .avif`.

| Имя файла          | Где используется                                  |
| ------------------ | ------------------------------------------------- |
| `main-page.*`      | Главный экран (Hero)                              |
| `main-page2.*`     | Раздел «О садике» — показывается целиком, без обрезки |
| любые другие       | Галерея (из `public/images/`)                     |

`main-page.*` и `main-page2.*` можно положить и в `public/images/`, и прямо в `public/` —
сначала ищется в `public/images/`.

В галерею не попадают `logo.*`, `favicon.*`, `icon.*`, `og.*`, скрытые файлы и точные
копии других фото. Фото автоматически раскладываются по ячейкам сетки по пропорциям:
вертикальные — в высокие ячейки, панорамы — в широкие.

Список фото собирается **при сборке** (`npm run build`). После добавления новых фото
пересоберите проект (на Vercel достаточно сделать новый деплой). Если фото нет,
сайт показывает аккуратные заглушки — сборка не ломается.

Совет: перед загрузкой уменьшайте фото до ~2000 px по длинной стороне.

## Ссылка на документы

Создайте файл `.env.local` (или переменную окружения в Vercel → Settings → Environment Variables):

```
NEXT_PUBLIC_DOCUMENTS_URL=https://drive.google.com/drive/folders/…
```

Пока переменная пустая, в разделе «Құжаттар» показывается сообщение
«Құжаттар жақын арада қолжетімді болады.» После указания ссылки и пересборки появится
кнопка «Құжаттарды қарау», открывающая ссылку в новой вкладке.

## Домен для SEO

`NEXT_PUBLIC_SITE_URL=https://ваш-домен.kz` — используется в canonical, sitemap, robots и Open Graph.
На Vercel без этой переменной автоматически берётся production-домен проекта.

## Где что менять

- `src/i18n/translations.ts` — все тексты на казахском и русском.
- `src/config/site.ts` — телефоны, Instagram, адрес, ссылки на карту.
- `src/components/` — разделы сайта; `src/components/decor/` — SVG-декор.
- `src/lib/images.ts` — поиск фотографий в `public/images`.

## Деплой на Vercel

Импортируйте папку/репозиторий в Vercel — настройки по умолчанию (Framework: Next.js) подходят.
Добавьте при необходимости `NEXT_PUBLIC_DOCUMENTS_URL` и `NEXT_PUBLIC_SITE_URL`.
